# LexiGuard AI ⚖️
**GenAI Legal Assistance & Access Intelligence Engine**

LexiGuard AI is an automated contract intelligence platform built with Gemini to simplify complex legal agreements, generate plain-English breakdowns, calculate quantifiable risk scores, and draft fair counter-clauses.

## Features
- **Automated Clause Risk Heatmap**: Classifies predatory, high, medium, and low-risk terms.
- **Side-by-Side Counter-Drafting**: Re-negotiates aggressive clauses into fair terms.
- **Counsel Consultation Sheet**: Generates actionable talking points for legal counsel.

## Tech Stack
- **AI Core**: Google Gemini API (`google-genai`)
- **Backend**: FastAPI, PyMuPDF, Pydantic
- **Frontend**: React (Vite), Tailwind CSS, Lucide Icons

*Disclaimer: LexiGuard AI provides informational assistance and is not certified legal counsel.*
